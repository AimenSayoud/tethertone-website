Install on the Mac

  1. Open the .dmg and drag AudioBridge into Applications. If you prefer an installer, the .pkg does the same thing and opens the app when it finishes.
  2. Open AudioBridge from Applications or Spotlight.
  3. Press Start. macOS asks for one permission, depending on the capture method: Screen & System Audio Recording by default, or Microphone for BlackHole.

“AudioBridge can't be opened” on first launch? The app is signed but not notarized by Apple, which requires a paid developer account. Open System Settings › Privacy & Security, scroll down and click Open Anyway. Or remove the download quarantine in Terminal:

xattr -dr com.apple.quarantine /Applications/AudioBridge.app

Install on Android

  1. Download the .apk on your phone. You can also copy it over from the Mac, or install it with adb install.
  2. Open it. If Android asks, allow your browser or file manager to install apps.
  3. Open AudioBridge and tap Scan pairing QR. It asks for the camera only while scanning, and for notifications so the playback notification can show.

Built AudioBridge from source before? Android won't update an app signed with a different key. Uninstall the old build first.

Optional: connect over USB

Wi-Fi needs nothing extra. For the lower-latency USB route:

  1. Enable USB debugging on the phone.
  2. Install adb on the Mac:
brew install android-platform-tools

Plug in the phone and accept the Allow USB debugging? prompt. AudioBridge sets up adb reverse by itself and puts the cable first in the QR code.

Verify the download

Every release publishes a SHA256SUMS file. Compare it with:

shasum -a 256 AudioBridge-*

The Android APK is signed with the project's release key. Its certificate SHA-256 fingerprint is:

B4:82:0A:7A:9E:FC:EA:23:99:5C:3A:F0:9E:26:52:0D:92:09:91:AC:FE:1C:D1:43:A5:9D:8F:0B:34:F7:09:2E

Build from source

The macOS app needs only the Xcode Command Line Tools; the Android app needs JDK 17 and the Android SDK.

git clone https://github.com/AimenSayoud/audiobridge.git
cd audiobridge/macos && ./make-signing-identity.sh && ./build.sh --install
cd ../android && ./gradlew :androidApp:installDebug

See BUILDING.md for tests, release builds and signing.
