Features

Built like an audio tool, not a screen-sharing hack

Two native apps and a small, documented protocol. Each part is built for one job: get the sound from your Mac to your phone intact, on time, and in sync.

Two ways to capture

Read the system mix directly with ScreenCaptureKit (nothing to install), or read a BlackHole loopback device with AVAudioEngine (Microphone permission only). Switch any time.

USB and Wi-Fi at once

The QR code lists every route to your Mac. The phone races them and keeps whichever answers first, so the cable wins when it's plugged in and Wi-Fi takes over when it isn't.

Stays in sync for hours

Two devices never agree on how long a second is. Tethertone corrects the difference continuously by playing a fraction of a percent fast or slow. It's inaudible, with no jumps and no creeping delay.

Pair once with a QR code

Scan the code and you're done. The phone remembers the Mac, reconnects on its own, and a random token keeps everyone else on your network out.

Plays with the screen off

A foreground service keeps audio going when the phone locks, with a Stop button in the notification. Put the phone in your pocket and walk around.

Diagnostics you can read

Round-trip time, buffer depth, underruns, lost packets and drift correction, live on both devices. When something goes wrong, you can see where.

Setup

Three steps, about a minute

No accounts, no drivers, no Audio MIDI Setup unless you want it.

  1. Start on the Mac

    Open Tethertone and press Start in the menu bar. macOS asks once for the permission the capture method needs.

  2. Scan the QR code

    On the phone, tap Scan pairing QR and point it at the code on the Mac's Pairing tab. Plug in the USB cable too if you like.

  3. Play anything

    Music, video, calls, games: whatever the Mac plays comes out of the phone. Next time, just press Start and the phone reconnects.

Capture methods

Your choice of permission

macOS offers two ways to hear what the Mac is playing. Tethertone supports both, and you switch between them from the window.

Screen Recording Default

Reads the system audio mix directly through ScreenCaptureKit. Nothing to install and your speakers keep working. macOS files it under screen recording because the API has no audio-only mode, but no image is ever read.

FAQ

Questions, answered

Can I use my Android phone as a speaker for my Mac?

Yes. Install Tethertone on the Mac and on the phone, press Start on the Mac and scan the QR code with the phone. Everything the Mac plays is then streamed to the phone's speaker or headphones, over a USB cable or Wi-Fi.

Is Tethertone free?

Yes. Tethertone is free and open source under the MIT License. There are no ads, no accounts, no subscriptions and no tracking.

Does it work over USB or only over Wi-Fi?

Both. Over USB it uses adb reverse, which needs USB debugging on the phone and adb on the Mac. Over Wi-Fi both devices must be on the same network. The pairing code lists every route and the phone uses whichever answers first, so the cable wins when it is plugged in.

How much latency does Tethertone add?

Latency is mostly the phone's jitter buffer, which you set between 20 and 250 ms; the default is 90 ms. Measured on USB with the default setting, the buffer held between 40 and 110 ms with no lost packets. Lower settings reduce latency at the cost of more dropouts on a busy network.

Why does macOS ask for Screen Recording permission?

The default capture method uses ScreenCaptureKit, the only macOS API that provides the whole system audio mix without a virtual driver. It has no audio-only mode, so macOS files it under screen recording. Tethertone never reads an image. To avoid the permission, install BlackHole and switch the capture method to BlackHole, which needs only the Microphone permission.

Do I need BlackHole or Soundflower?

No. The default Screen Recording method needs nothing installed. BlackHole is an optional alternative for people who prefer not to grant the Screen Recording permission.

Is the audio encrypted?

No. A random token in the QR code stops other people on your network from connecting, but the audio itself travels unencrypted. On a network you do not trust, use the USB cable or a VPN such as Tailscale.

Does it work with iPhone, Windows or Linux?

Not yet. The sender is a macOS app and the receiver is an Android app. The wire protocol is documented, so other senders and receivers can be built on it.

How much data does streaming use?

About 1.5 Mbit/s, roughly 690 MB per hour, because the audio is uncompressed 16-bit stereo PCM. That is nothing over USB or home Wi-Fi, but expensive on a metered mobile connection.

Can several phones listen at the same time?

Yes. The Mac serves any number of phones at once, each with its own send queue so a slow phone cannot hold up the others. It has been tested with two.
